### 🔍 [ThreatLens — Threat Intelligence Platform](https://github.com/Nadhil-an/ThreatLens-Threat-Intelligence-and-Threat-Monitoring-)
> Live deployed SOC dashboard for real-time threat intelligence aggregation and monitoring

- Aggregates threat data from **VirusTotal** and **AbuseIPDB** to detect suspicious IPs and domains
- Classifies threats by type (Credential Harvesting, Suspicious Activity) with **severity scoring 1–10**
- Built with **Python/Django** backend, SQLite database, and HTML/CSS/JS frontend
- 🌐 **Live Demo:** [threatlens-hqht.onrender.com](https://threatlens-hqht.onrender.com)

`Python` `Django` `VirusTotal API` `AbuseIPDB` `SQLite` `Threat Intelligence`
